# 🅿️ SmartPark — Smart Parking Management System

A modern frontend prototype for managing parking operations in malls, hospitals, offices, airports, hotels, and other managed facilities.

## Features
- Live parking occupancy dashboard
- Floor-wise parking map
- Available / occupied / reserved slot states
- Vehicle entry and exit simulation
- Digital ticket concept
- Parking fee calculation concept
- ANPR/computer-vision integration concept
- Responsive UI

## Current Version
This is a static HTML/CSS/JavaScript prototype. Entry/exit and parking status are simulated in the browser.

## Planned Full-Stack Version
- React.js frontend
- Java + Spring Boot backend
- PostgreSQL
- Redis
- WebSockets
- Spring Security + JWT
- QR ticketing
- ANPR / OpenCV / YOLO
- IoT sensor integration with ESP32
- Admin analytics
- Payment gateway
- Docker deployment

## Run Locally
Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Render
Deploy as a Render Static Site:
- Branch: `main`
- Build Command: empty
- Publish Directory: `.`
